# Triage labels

技能以五個標準 triage 角色描述 issue 狀態。本文件將各角色對應到本儲存庫實際使用的 GitHub label。

| mattpocock/skills 中的角色 | 本儲存庫的 label | 說明 |
| -------------------------- | ---------------- | ---- |
| `needs-triage`             | `needs-triage`   | 維護者需要評估此 issue |
| `needs-info`               | `needs-info`     | 等待回報者提供更多資訊 |
| `ready-for-agent`          | `ready-for-agent`| 規格完整，可交由非同步代理處理 |
| `ready-for-human`          | `ready-for-human`| 需要由人工實作 |
| `wontfix`                  | `wontfix`        | 不會處理 |

技能提及角色（例如「套用可交由代理處理的 triage label」）時，請使用表格中的對應 label。若儲存庫的 label 命名改變，請更新「本儲存庫的 label」欄。
